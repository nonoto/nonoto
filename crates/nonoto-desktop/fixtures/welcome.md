# Nonotoへようこそ

Nonotoは、正本を手元に置く**ローカルファースト**なドキュメント共有サービスです。

## できること

- ページを書いて保存する
- ページを一覧から選んで読む
  - 本文はMarkdownで書く

1. 左の一覧からページを選ぶ
2. 右に本文が表示される

> 引用の文

| 項目   | 内容         |
| ------ | ------------ |
| 保存先 | 端末の中     |
| 本文   | Markdown     |

```rust
fn main() {
    println!("こんにちは");
}
```

- [ ] まだのタスク
- [x] 済んだタスク
